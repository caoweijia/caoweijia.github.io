RWKVSR: Receptance Weighted Key-Value Network for Hyperspectral Image Super-Resolution

2026-11-16

Hyperspectral image super-resolution (HSISR) is a critical task in remote sensing, aiming to reconstruct high-resolution images from low-resolution inputs while preserving both spatial details and spectral information. While deep learning has significantly advanced this field, existing methods often rely on 2D/3D convolutions or standard Transformer architectures. These approaches face inherent limitations, including restricted receptive fields, quadratic computational complexity, and insufficient fusion of spatial-spectral dependencies. To address these challenges, we propose RWKVSR, a lightweight network that integrates the Receptance Weighted Key-Value (RWKV) architecture for efficient HSISR.

Our method is built upon three key components. First, we replace quadratic self-attention with a linear-complexity RWKV module, which enables efficient global spectral-spatial modeling without the prohibitive computational cost of traditional Transformers. Second, we introduce a Spectral-Spatial Residual Module (SSRM) that employs anisotropic, direction-separable 3D convolutions. This design allows for the hierarchical extraction of multi-scale features while enhancing interactions between local and global contexts. Third, we develop a Hyperspectral Frequency Loss (HFL) that optimizes spectral consistency by prioritizing high-frequency structural alignment between the reconstructed and ground-truth images in the frequency domain.

Extensive experiments on the CAVE and Harvard datasets demonstrate that RWKVSR outperforms existing state-of-the-art methods. The results indicate that our approach effectively balances reconstruction accuracy with computational efficiency. By leveraging the linear complexity of the RWKV architecture and targeted frequency-domain optimization, RWKVSR provides a practical solution for high-quality hyperspectral image reconstruction. This work contributes to the development of more efficient and accurate AI models for remote sensing applications, where processing large volumes of spectral data is essential. The code for our implementation is publicly available to facilitate further research and application in the field.

*Yang Xiaofei, Li Chunshan, Cao Weijia*, Tang Dong*, Ban Yifang, Zhou Yicong. RWKVSR: Receptance Weighted Key-Value Network for Hyperspectral Image Super-Resolution. IEEE Transactions on Circuits and Systems for Video Technology, 2025.* Paper
