SSLANet: A Frequency–Spatial Visual System for Efficient Hyperspectral Image Classification

2026-11-03

Hyperspectral image classification requires a compact representation that jointly captures discriminative spectral cues, local spatial structures, and efficient inference under limited annotations. Existing convolutional approaches extract local patterns well but struggle with long-range spectral dependencies. Transformer-based models improve global interaction but incur high computational costs, while recent state-space models often overlook transform-domain spectral variations. To address these limitations, we propose SSLANet, a frequency-spatial learning network designed for efficient hyperspectral classification.

Our method introduces a residual frequency-spatial layer that integrates an adaptive spectral block and an interactive convolution block. The adaptive spectral block performs learnable complex-valued spectral modulation combined with input-dependent frequency-energy selection to enhance material-sensitive responses. The interactive convolution block propagates filtered features into local neighborhoods through multiplicative spatial-channel interaction. Crucially, our design conditions the frequency response on the current input distribution using a soft mask and a latent transfer function, moving beyond fixed transform-domain preprocessing.

We validate our approach on three public hyperspectral benchmarks. The experiments show that SSLANet achieves competitive classification accuracy while maintaining favorable computational efficiency. This work matters for remote sensing and AI because it provides a scalable, resource-efficient alternative to heavy attention mechanisms. By dynamically adapting to spectral variations without excessive overhead, our framework enables more practical deployment of hyperspectral analysis in real-world monitoring and security applications where data volume and computational constraints are significant.
